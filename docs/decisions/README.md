# Decisions

Records of lasting choices that future work must inherit: product, architecture, data, security,
compatibility and validation. Each says what forced the choice, what was decided, what was rejected,
and what follows from it. Task-level choices do not need one.

An accepted record is not rewritten. When a choice changes, add a new record that says it supersedes
the old one.
